## ✨ Features

- **One-click cloning** — Just run the script
- Beautiful colored **CLI output** with progress
- Automatically skips heavy folders (`node_modules`, `vendor`, `.git`, etc.)
- Generates a **professional HTML report** with stats
- Shows copy duration, total size, and file count
- Clean folder structure with timestamped destination
- Works both in **Terminal** and **Browser**

## 🛠️ How to Use

### 1. Setup

1. Download or clone this repository
2. Place your project inside a folder named **`pending_project`**
3. Put `clone.php` in the parent directory

**Folder Structure:**
```bash
your-folder/
├── clone.php
└── pending_project/
    ├── index.php
    ├── assets/
    ├── config/
    └── ...
2. Run the Cloner
Using Terminal:
Bashphp clone.php
Or open directly in browser:
texthttp://localhost/your-folder/clone.php
